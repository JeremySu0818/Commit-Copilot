# Commit Copilot अपडेट जानकारी

## संस्करण 1.18.0 में नया क्या है

- एक ही टूल अनुरोध में कई फ़ाइलों के diff प्राप्त करने और प्रत्येक अनुरोधित फ़ाइल का पूरा सटीक diff लौटाने का समर्थन जोड़ा गया।
- कमिट संदेश निर्माण को अंतिम रूप देने से पहले सभी परिवर्तित फ़ाइलों का निरीक्षण सुनिश्चित करने के लिए पूर्ण diff कवरेज अनिवार्यता लागू की गई।
- जनरेशन रद्द करने पर LLM प्रदाताओं के लिए सक्रिय HTTP अनुरोधों को तुरंत रोकने के लिए अनुरोध रद्द करने की समस्या को ठीक किया गया।
