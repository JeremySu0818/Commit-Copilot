# Commit Copilot Update Info

## What’s New in Version 1.24.0

- Updated AI SDKs and provider APIs, with dynamic model discovery. Model availability and compatibility depend on the provider and account. Model names are no longer hard-coded in the model list.
- Improved support for OpenAI Responses, custom endpoints, Qwen, and local Ollama models.
- Generation requests rejected with HTTP 400 now suggest trying another model when the current model or settings may be unsupported.
