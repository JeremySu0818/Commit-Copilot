# Commit Copilot Informace o aktualizaci

## Novinky ve verzi 1.24.0

- Aktualizovány AI SDK a API poskytovatelů s dynamickým načítáním modelů. Dostupnost a kompatibilita závisejí na poskytovateli a účtu. Názvy modelů již nejsou pevně zakódovány v seznamu modelů.
- Vylepšena podpora OpenAI Responses, vlastních endpointů, Qwen a místních modelů Ollama.
- Při chybě HTTP 400 během generování aplikace doporučí zkusit jiný model, protože model nebo nastavení nemusí být podporovány.
