# Commit Copilot Información de actualización

## Novedades de la versión 1.24.0

- Se actualizaron los SDK de IA y las API de los proveedores, con descubrimiento dinámico de modelos. La disponibilidad y compatibilidad dependen del proveedor y la cuenta. Los nombres de los modelos ya no están codificados en la lista.
- Se mejoró la compatibilidad con OpenAI Responses, endpoints personalizados, Qwen y modelos locales de Ollama.
- Si una solicitud de generación recibe HTTP 400, se sugiere probar otro modelo porque el modelo o sus ajustes podrían no ser compatibles.
