# Commit Copilot Frissítési információk

## Újdonságok az 1.25.0 verzióban

- Új billentyűkombináció a commit üzenet generálásához: `Ctrl+Alt+G` (`Cmd+Option+G` macOS-en) – ugyanaz a művelet, mint a Forrásvezérlés varázspálca ikonjára kattintás. A **Billentyűkombinációk** ablakban megváltoztatható.
