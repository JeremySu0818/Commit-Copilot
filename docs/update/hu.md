# Commit Copilot frissítési információk

## Újdonságok az 1.20.0-s verzióban

- Az Ollama thinking mód letiltása az Agent és Direct Diff kérésekben a commit üzenetek és eszközhívások megfelelő visszaküldésének biztosítása érdekében.
- Javítva a Google Gemini eszközhívások hibája, a függvénydeklarációs paraméterek natív JSON Schema mezőn keresztüli helyes átadásával.
- Gemini 3.8 Flash támogatás hozzáadása a Google Gemini szolgáltatóhoz, és az alapértelmezett Google modell frissítése Gemini 3.8 Flash-re.
- GPT-6 Astra támogatás hozzáadása az OpenAI szolgáltatóhoz.
- Claude Fable 5.1 támogatás hozzáadása az Anthropic Claude szolgáltatóhoz.
- A DeepSeek modellkatalógus frissítése a DeepSeek V4.1 Flash modellel, valamint az elavult modellek eltávolítása.
