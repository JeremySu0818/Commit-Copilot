# Commit Copilot frissítési információk

## Újdonságok az 1.21.0-s verzióban

- Javítva az OpenAI végponti eszközhívások hibája, amelyeket a nem támogatott séma-kulcsszavak okoztak, megfelelően megtisztítva a paramétersémákat a függvényhívásokhoz és a Responses API-hoz.
- GPT-6 Luna, GPT-6 Sol és GPT-6.1 Sol támogatás hozzáadása az OpenAI szolgáltatóhoz, és az alapértelmezett OpenAI modell frissítése GPT-6.1 Sol-ra.
- Claude Opus 5.5 támogatás hozzáadása az Anthropic Claude szolgáltatóhoz.
- Grok 4.7 támogatás hozzáadása az xAI Grok szolgáltatóhoz.
- A Groq modellkatalógus frissítése a Qwen 3.8 27b modellel, valamint az elavult modellek eltávolítása.
