# Commit Copilot अपडेट जानकारी

## संस्करण 1.24.0 में नया

- AI SDK और प्रदाता API अपडेट किए गए हैं और मॉडल सूची अब गतिशील रूप से प्राप्त होती है। उपलब्धता और संगतता प्रदाता और खाते पर निर्भर करती है। मॉडल सूची में मॉडल नाम अब हार्डकोड नहीं हैं।
- OpenAI Responses, कस्टम एंडपॉइंट, Qwen और स्थानीय Ollama मॉडल का समर्थन बेहतर किया गया।
- जनरेशन में HTTP 400 मिलने पर दूसरा मॉडल आज़माने का सुझाव दिया जाता है, क्योंकि मॉडल या सेटिंग समर्थित न हो सकती है।
