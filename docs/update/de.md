# Commit Copilot Update-Informationen

## Neuerungen in Version 1.25.0

- Neues Tastenkürzel für die Generierung von Commit-Nachrichten: `Strg+Alt+G` (`Cmd+Option+G` auf macOS) – dieselbe Aktion wie die Zauberstab-Schaltfläche der Quellcodeverwaltung. Das Kürzel lässt sich in den Tastenkürzeln anpassen.
