# Информация об обновлении Commit Copilot

## Что нового в версии 1.21.0

- Исправлена ошибка, из-за которой вызовы инструментов эндпоинта OpenAI завершались сбоем из-за неподдерживаемых ключевых слов схемы: схемы параметров для вызова функций и Responses API теперь корректно фильтруются.
- Добавлена поддержка GPT-6 Luna, GPT-6 Sol и GPT-6.1 Sol для провайдера OpenAI, а модель OpenAI по умолчанию обновлена до GPT-6.1 Sol.
- Добавлена поддержка Claude Opus 5.5 для провайдера Anthropic Claude.
- Добавлена поддержка Grok 4.7 для провайдера xAI Grok.
- Обновлен каталог моделей Groq: добавлен Qwen 3.8 27b, а устаревшие модели удалены.
