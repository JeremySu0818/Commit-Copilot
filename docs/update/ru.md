# Информация об обновлении Commit Copilot

## Что нового в версии 1.20.0

- Отключен режим thinking в Ollama для запросов в режимах Agent и Direct Diff, чтобы обеспечить корректный возврат сообщений коммита и вызовов инструментов.
- Исправлена ошибка, из-за которой вызовы инструментов в Google Gemini завершались сбоем: параметры объявлений функций теперь корректно передаются через исходное поле JSON Schema.
- Добавлена поддержка Gemini 3.8 Flash для провайдера Google Gemini, а модель Google по умолчанию обновлена до Gemini 3.8 Flash.
- Добавлена поддержка GPT-6 Astra для провайдера OpenAI.
- Добавлена поддержка Claude Fable 5.1 для провайдера Anthropic Claude.
- Обновлен каталог моделей DeepSeek: добавлен DeepSeek V4.1 Flash, а устаревшие модели удалены.
