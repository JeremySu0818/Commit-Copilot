# Commit Copilot Информация об обновлении

## Что нового в версии 1.24.0

- Обновлены SDK ИИ и API поставщиков; модели обнаруживаются динамически. Доступность и совместимость зависят от поставщика и учётной записи. Имена моделей больше не заданы жёстко в списке моделей.
- Улучшена поддержка OpenAI Responses, пользовательских конечных точек, Qwen и локальных моделей Ollama.
- При HTTP 400 во время генерации предлагается попробовать другую модель, поскольку модель или настройки могут не поддерживаться.
