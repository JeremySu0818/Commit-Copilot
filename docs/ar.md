# معلومات تحديث Commit Copilot

## الميزات الجديدة في الإصدار 1.18.0

- إضافة دعم للاستعلام عن فروقات ملفات متعددة في طلب أداة واحد مع إعادة الفرق الكامل والدقيق لكل ملف مطلوب.
- إضافة إعداد اختياري للتغطية الكاملة للفروقات، مع تعطيله افتراضيًا، ليتطلب فحص كل ملف معدّل قبل إنهاء رسالة الالتزام عند تفعيله.
- إصلاح إلغاء الطلبات لإنهاء الاتصالات النشطة عبر HTTP مع مزودي LLM فورًا عند إلغاء التوليد.
