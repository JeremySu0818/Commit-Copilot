# Informations de mise à jour de Commit Copilot

## Nouveautés de la version 1.18.0

- Ajout de la prise en charge de plusieurs diffs de fichiers dans une seule demande d'outil, avec renvoi du diff exact complet de chaque fichier demandé.
- Ajout d'un réglage facultatif de couverture complète des diffs, désactivé par défaut, qui exige l'inspection de tous les fichiers modifiés avant de finaliser le message de commit lorsqu'il est activé.
- Correction de l'annulation des requêtes pour interrompre immédiatement les connexions HTTP actives vers les fournisseurs LLM lors de l'annulation.
