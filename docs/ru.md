# Информация об обновлении Commit Copilot

## Что нового в версии 1.18.0

- Добавлена поддержка запроса diff нескольких файлов в одном вызове инструмента с возвратом полного точного diff каждого запрошенного файла.
- Введен обязательный контроль покрытия diff для проверки всех измененных файлов перед завершением генерации сообщения коммита.
- Исправлена отмена запросов для немедленного прекращения активных HTTP-соединений с провайдерами LLM при отмене генерации.
