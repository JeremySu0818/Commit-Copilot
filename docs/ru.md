# Информация об обновлении Commit Copilot

## Что нового в версии 1.19.0

- Добавлена поддержка Gemini 3.7 Flash для провайдера Google Gemini, а модель Google по умолчанию обновлена до Gemini 3.7 Flash.
- Добавлена поддержка Claude Opus 5 для провайдера Anthropic Claude.
- Добавлена поддержка Grok 4.5 и Grok 4.6 для провайдера xAI Grok, а модель по умолчанию обновлена до Grok 4.6.
- Обновлен каталог моделей Groq: добавлены MiniMax M2.7 и Qwen 3.6 27b, а устаревшие модели удалены.
- Улучшена обработка моделей для пользовательских OpenAI-совместимых провайдеров при использовании настраиваемых Base URL.
