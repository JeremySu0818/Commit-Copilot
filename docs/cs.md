# Informace o aktualizaci Commit Copilot

## Novinky ve verzi 1.18.0

- Přidána podpora pro získání diffů více souborů v jediném požadavku nástroje s vrácením úplného přesného diffu každého požadovaného souboru.
- Vynuceno kompletní pokrytí inspekce diffů pro zajištění kontroly všech změněných souborů před dokončením generování zprávy commitu.
- Opraveno zrušení požadavků tak, aby se při zrušení generování okamžitě ukončila aktivní HTTP spojení s poskytovateli LLM.
